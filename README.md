# ロボット イライラ棒

ロボットハンドに持たせたApple Pencilで、iPadのジグザグコースをなぞるイライラ棒ゲーム。
イベントで大人数が連続挑戦できるように作っています。人がタップする操作はありません。

- ゲーム: https://tnmtrt-pixel.github.io/iraira-bou/
- ランキング画面（別タブレット用）: ゲームの ⚙︎設定 に表示されるQRコード／URLから開く（`ranking.html?room=部屋コード`）

## 流れ
1. 大きな START 円にペンを置いた瞬間に計測開始 → そのままコースをなぞる
2. GOAL でクリア／壁・ペン離れ・時間切れでアウト
3. 結果を数秒表示 → 自動で次の挑戦者（番号は自動採番）

## ランキング連携
結果は無料の中継サービス ntfy.sh 経由で送信（挑戦番号・タイム・到達率のみ）。
ネットワークで ntfy.sh がブロックされていると届きません。
